# Chapter 17 — Working with APIs

## Overview

This chapter introduces the concept of **Application Programming Interfaces (APIs)** and demonstrates how Python can retrieve and process live data from web services.

Using the **GitHub API** and the **Hacker News API**, the chapter shows how Python programs can send HTTP requests, receive structured data in **JSON format**, and transform that data into meaningful visualizations.

The primary goal is to learn how to **interact with online services programmatically**, extract relevant information from API responses, and present that information through **interactive charts and visualizations**.

---

## Topics Covered

- Understanding how web APIs work
- Sending HTTP requests with the `requests` library
- Parsing JSON responses from APIs
- Exploring the GitHub REST API
- Retrieving repository information programmatically
- Extracting nested data structures from API responses
- Visualizing API data with Plotly
- Working with the Hacker News API
- Handling network errors and incomplete responses
- Implementing basic API testing with `pytest`

---

## Exercises

This folder contains implementations for:

- Retrieving the most-starred repositories from the GitHub API
- Visualizing GitHub repository popularity with interactive bar charts
- Modifying API queries to analyze repositories from different programming languages
- Retrieving Hacker News submissions through the Hacker News API
- Visualizing the most active discussions based on comment counts
- Handling invalid or incomplete API responses with `try`/`except`
- Writing tests to verify successful API responses

## Key Concepts Practiced

- Making HTTP requests from Python
- Processing JSON API responses
- Extracting nested fields from complex data structures
