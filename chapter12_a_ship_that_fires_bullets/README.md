# Chapter 12 — Alien Invasion (Pygame Game Project)

This chapter introduces game development basics using **Pygame**.

## What I Built

- A fullscreen game window  
- A movable ship sprite  
- Smooth keyboard controls  
- Continuous game loop  
- Frame rate control with `Clock`

## Concepts Practiced

- Event handling (`KEYDOWN`, `KEYUP`)
- Movement using flags
- Updating position with float precision
- Preventing objects from leaving the screen
- Redrawing the screen each frame
