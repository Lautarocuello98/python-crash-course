# Chapter 15 — Generating Data

## Overview

This chapter introduces data visualization in Python using **Matplotlib** and **Plotly**.

The focus is on generating datasets, simulating random processes, and presenting the results through visual representations. By visualizing data such as mathematical functions, random walks, and dice simulations, this chapter demonstrates how graphical output can reveal patterns that are difficult to see in raw numbers.

---

## Topics Covered

- Creating scatter plots with Matplotlib
- Customizing charts (titles, labels, styles, colors)
- Visualizing mathematical sequences
- Simulating random walks
- Building reusable classes for simulations
- Rolling dice and analyzing results
- Creating interactive bar charts with Plotly
- Using list comprehensions for data generation
