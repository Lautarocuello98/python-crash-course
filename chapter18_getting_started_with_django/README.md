# Chapter 18 — Getting Started with Django

## Overview

This chapter introduces **Django**, a high-level Python web framework designed to help developers build robust web applications quickly and efficiently.

The chapter focuses on understanding how Django organizes projects into **projects and apps**, and how it handles requests using its **Model–Template–View (MTV)** architecture.

Through the creation of a simple web project and a basic application, the chapter demonstrates how Django routes user requests, generates responses, and connects application logic to web pages.

The main objective is to learn how to **structure a web application**, define **URL routes**, create **views**, and render content using Django’s built-in tools.

---

## Topics Covered

- Understanding the Django web framework
- Installing and configuring Django
- Creating a Django project
- Understanding the Django project structure
- Creating and registering Django apps
- Working with Django’s MTV (Model–Template–View) architecture
- Routing requests using `urls.py`
- Creating views to handle HTTP requests
- Returning responses with `HttpResponse`
- Running the Django development server
- Using the Django admin interface
- Creating a superuser account

## Notes

This chapter introduces the **fundamental building blocks of Django applications**.

Rather than focusing on complex features, the chapter emphasizes how Django structures web projects and how individual components interact within the framework.

By learning how to create projects, apps, views, and URL routes, developers gain the foundation required to build more advanced web applications using Django.
