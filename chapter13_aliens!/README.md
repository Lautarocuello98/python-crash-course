# Chapter 13 — Aliens! (Pygame Game Project)

## Overview

This chapter introduces game development using the Pygame library.

A complete arcade-style game is built step by step, where the player controls a ship that shoots down fleets of aliens.

The focus is on structuring larger programs using classes, managing sprites, and handling real-time game loops.

---

## Topics Covered

- Installing and using Pygame
- Game loop structure
- Event handling (keyboard input)
- Sprite-based game objects
- Managing groups of sprites
- Collision detection
- Object-oriented game design

---

## Exercises

This folder contains:

- Ship movement implementation
- Bullet firing mechanics
- Alien fleet generation
- Collision detection between bullets and aliens
- Basic game structure using classes

---

## Key Concepts Practiced

- Real-time program loops
- Event-driven programming
- Object-oriented design
- Sprite management
- Collision detection

---

## Notes

This chapter focuses on building a structured game architecture.

Even though the game logic is simple, it introduces patterns used in real game development such as sprite groups, update loops, and separation of responsibilities between classes.
