# Chapter 14 — Scoring (Pygame Game Improvements)

## Overview

This chapter expands the Alien Invasion game by adding a scoring system and game progression features.

The player can now earn points by destroying aliens, track high scores, and advance through increasingly difficult levels.

The focus is on enhancing the game experience by introducing player feedback and dynamic difficulty.

---

## Topics Covered

- Implementing a scoring system
- Displaying score and high score on the screen
- Tracking player progress
- Adding game levels
- Increasing game difficulty over time
- Using Pygame fonts for on-screen text
- Updating UI elements during gameplay

---

## Exercises

This folder contains:

- Score tracking implementation
- High score system
- Level progression
- Increasing alien speed per level
- Displaying score and level on screen

---

## Key Concepts Practiced

- Managing game state
- Dynamic difficulty adjustment
- Rendering text with Pygame
- Updating UI elements in real time
- Extending an existing codebase

---

## Notes

This chapter focuses on improving gameplay feedback and progression.

By introducing scoring, levels, and increasing difficulty, the game becomes more engaging while reinforcing the importance of clean architecture and modular design in larger projects.
