# Python Crash Course (3rd Edition)

## About this repository

This repository contains my exercises and projects while studying *Python Crash Course (3rd Edition)* by Eric Matthes.

The focus is on building strong Python fundamentals and applying them through progressively structured projects.

Core areas covered:

- Python fundamentals  
- Data structures  
- Control flow  
- Functions  
- Object-Oriented Programming  
- File handling and exceptions  
- Testing  
- Game development with Pygame  
- Data visualization  
- Web development with Django

## How to run

Clone the repository:

```bash
git clone https://github.com/Lautarocuello98/python-crash-course.git
cd python-crash-course
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the environment:

Windows (PowerShell):

```bash
.venv\Scripts\Activate.ps1
```

Windows (CMD):

```bash
.venv\Scripts\activate.bat
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Install dependencies (for project chapters):

```bash
pip install -r requirements.txt
```

Run a script (example):

```bash
python chapter_09/Projects/restaurant.py
```
